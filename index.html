Release 1 · GridWorld

Simple mazes. Hidden rules.

Each R1 maze is a GridWorld puzzle governed by hidden causal mechanisms — switches that open walls, keys that gate doors, effects that fire at a distance. Solving one takes genuine spatial reasoning and long-horizon planning, not pattern-matching. A child manages it; frontier models mostly don't.

Release 1 covers GridWorld. The full v2.0 will render the same task three ways — so a model that only memorized one interface has nowhere to hide:

GridWorld · Release 1

Symbolic grid

The maze as a grid of cells, walls, and switches. Pure spatial reasoning — no rendering, no language, just the structure of the problem.

Natural Language · Coming

Described in text

The same maze in prose. The model must build and hold a spatial model of the world from a narrative it reads step by step.

3D · Coming

First-person 3D

The same maze as a 3D environment. Perception, navigation, and the same causal mechanics — grounded in pixels and movement.
