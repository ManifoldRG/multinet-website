# Model brand marks

`claude.svg`, `kimi.svg`, `qwen.svg` are the official brand glyphs as published by
[Simple Icons](https://simpleicons.org) (icon paths released CC0; the marks themselves
remain trademarks of their respective owners and are used here only to identify the
models evaluated in MultiNet v2.0 R1).

`openai.svg` is the OpenAI glyph from Simple Icons
[15.0.0](https://cdn.jsdelivr.net/npm/simple-icons@15.0.0/icons/openai.svg), the last
major release that carried it (Simple Icons removed it in 16.0.0, #13944), under the same
terms.

They are rendered via CSS `mask`, so the shape is taken from the file and the colour
comes from CSS. Editing the `fill` inside these files therefore has no effect.
