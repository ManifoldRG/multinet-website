v2.0 · Release 1 — GridWorld

Simple mazes that break frontier models.

Release 1 puts frontier models in GridWorld: mazes with hidden causal structure that demand real spatial reasoning and long-horizon planning — the kind a child solves in seconds. The strongest models solve just 2.7%. It's the first domain of MultiNet v2.0, whose full benchmark will render the same task several ways.

The idea

One maze. Hidden rules.

Every R1 instance is a GridWorld maze governed by causal mechanisms a model must discover to solve it — switches that open walls, keys that gate doors, effects that fire at a distance. Because the task holds real spatial and long-horizon structure, performance isolates a single question: does the model understand the problem, or just pattern-match its way through?

R1 covers GridWorld. The full v2.0 will render the same task three ways — so a model that only memorized one interface has nowhere to hide:

GridWorld · Release 1

Symbolic grid

The maze as a grid of cells, walls, and switches. Pure spatial reasoning — no rendering, no language, just the structure of the problem.

Methodology

Built to resist contamination and saturation.

Most benchmarks are a fixed set of problems. Once they leak into training data, or once models catch up, the number stops meaning anything. v2.0 is a generator, not a list.

Procedurally generated

No fixed test set to memorize

Instances are sampled from a generator, so we can always produce fresh, never-before-seen mazes. There is no static answer key to contaminate.

Tunable difficulty

No ceiling to saturate

Difficulty scales along explicit axes — maze size, solution length, number of causal mechanisms, distractors — so the benchmark grows with the models it measures.

Cross-domain by construction

Memorization has nowhere to hide

Rendering the same task several ways will turn "did it generalize?" into a direct, measurable comparison rather than an inference.

Human-anchored

A floor we can trust

These are mazes people solve easily. Human performance gives every score an honest reference point — and makes model failures legible.

Release 1

Start with GridWorld.

R1 is methodology-first. Before the full three-domain benchmark, we establish the foundation in the cleanest domain — the symbolic grid — where nothing sits between the model and the structure of the task.

Release 1 defines and validates:

  • The difficulty axes — how maze size, solution length, and causal complexity trade off, and how we calibrate them.
  • The evaluation protocol — how models are prompted, scored, and compared, and how we control for prompt and format effects.
  • Per-model failure analysis — not just whether models fail, but where and how they fall apart as difficulty climbs.
  • The final GridWorld evaluation set — the calibrated instances the leaderboard is scored on.

Natural language and 3D build on this same scaffolding, culminating in the full cross-domain benchmark, task generator, and paper.
